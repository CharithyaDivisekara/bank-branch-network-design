Secure Bank Branch Network Design

Project Overview
This project demonstrates a secure and cost-effective network design for a small bank branch using Cisco Packet Tracer.

Objectives
    Separate departments using VLANs.
    Configure inter-VLAN routing using Router-on-a-Stick.
    Assign IP addresses using DHCP.
    Apply ACLs to control network access.
    Test connectivity and basic network security.

VLAN and IP Addressing Plan

    VLAN     Department     Network
    
    10       Teller         192.168.10.0/24
    20       Manager        192.168.20.0/24
    30       CCTV           192.168.30.0/24
    40       Guest Wi-Fi    192.168.40.0/24
    50       Server         192.168.50.0/24
